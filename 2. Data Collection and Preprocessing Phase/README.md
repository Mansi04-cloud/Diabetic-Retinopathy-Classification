# 2. Data Collection and Preprocessing Phase

## Dataset Information
The dataset consists of retinal images categorized into:
- No DR
- Mild
- Moderate
- Severe
- Proliferative DR

## Data Source
Publicly available Diabetic Retinopathy datasets.

## Data Preprocessing Steps
- Image resizing
- Normalization
- Data augmentation
- Splitting into training and validation sets

## Libraries Used
- NumPy
- OpenCV
- TensorFlow
- Keras

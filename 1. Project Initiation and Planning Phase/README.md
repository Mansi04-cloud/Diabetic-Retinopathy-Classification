# 1. Project Initiation and Planning Phase

## Objective
The objective of this project is to build a Deep Learning based web application 
to classify Diabetic Retinopathy from retinal images.

## Problem Statement
Diabetic Retinopathy is a diabetes complication that affects the eyes.
Early detection is crucial to prevent blindness.

## Tools & Technologies Planned
- Python
- Flask
- TensorFlow / Keras
- HTML, CSS
- SQLite Database
